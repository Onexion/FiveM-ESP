In case you are wondering, you need to clone github into the project. You need:
```
imgui/
├── imgui.cpp
├── imgui.h
├── imgui_draw.cpp
├── imgui_tables.cpp
├── imgui_widgets.cpp
├── imgui_internal.h
├── imconfig.h
├── imstb_rectpack.h
├── imstb_textedit.h
├── imstb_truetype.h
└── backends/
    ├── imgui_impl_win32.cpp
    ├── imgui_impl_win32.h
    ├── imgui_impl_dx11.cpp
    └── imgui_impl_dx11.h
```
